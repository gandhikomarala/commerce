# NovaStore — Minimalist Architectural Tech & Hardware E-Commerce

High-end minimalist tech hardware store featuring category filtering, stock availability indicators, persistent cart drawer, discount coupon validation, and express checkout.

## Product Highlights
- **Domain**: E-Commerce
- **Visual Theme**: Minimalist Graphite & Sandstone Beige
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
